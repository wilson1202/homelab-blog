## 概述

本仓库用于归纳 Proxmox VE（当前稳定版 9.2，2026-08 发布；9.2-1 ARM64 ISO 已于 2026-08-05 推出）相关的操作记录、排查笔记与官方资料索引。

Proxmox VE（PVE）是基于 QEMU/KVM 与 LXC 的开源虚拟化平台，内置 Web 界面，可管理虚拟机、容器、集群、软件定义存储（含 Ceph/ZFS）与网络、以及内置防火墙与高可用（HA）。代码以 AGPL-3 授权，由 Proxmox Server Solutions GmbH 维护。

不在本笔记范围。本文档只做导航与说明，具体步骤见各子文档。
