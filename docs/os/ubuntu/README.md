## 概述

本仓库用于归纳 Ubuntu（由 Canonical 维护，当前 LTS 为 26.04 "Resolute Raccoon"，于 2026 年发布；上一个 LTS 为 24.04 LTS）相关的操作记录、排查笔记与官方资料索引。

Ubuntu 是基于 Debian 的 GNU/Linux 发行版，采用「LTS 每两年 4 月发布、标准支持 5 年」的节奏（LTS 可经 Ubuntu Pro 扩展至 15 年安全维护）。核心组件为：APT/Snap 包管理、Netplan 网络配置、systemd、Subiquity 安装器。衍生形态包括 Ubuntu Server、Desktop、WSL、Core（不可变/边缘）与各类 Flavor。

本文档只做导航与说明，具体步骤见各子文档。
