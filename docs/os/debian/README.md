## 概述

本仓库用于归纳 Debian（当前稳定版 13 trixie，于 2025-08-09 发布，最新点版 13.6 / 2026-07-11；oldstable 为 12 bookworm）相关的操作记录、排查笔记与官方资料索引。

Debian 是纯社区驱动的通用 GNU/Linux 操作系统，发行周期采用「stable / testing / unstable(sid)」三线，稳定版提供 3 年完整支持 + 2 年 LTS。核心组件为：APT 包管理、systemd、netinst 安装器、deb 软件包格式。

本文档只做导航与说明，具体步骤见各子文档。
