## 概述

本仓库用于归纳 fnOS（飞牛私有云，由广州铁刃智造开发）相关的操作记录、排查笔记与官方资料索引。

fnOS 是一款基于 Linux（Debian 发行版）深度开发的国产 NAS 操作系统，个人使用正版免费，支持主流 x86 硬件自由组装，并提供 ARM 公开测试版。核心特性为：存储空间管理、飞牛影视（海报墙/转码）、AI 相册、FN Connect 远程访问、虚拟机与硬件直通、应用中心（Docker 类容器应用）。

本文档只做导航与说明，具体步骤见各子文档。
