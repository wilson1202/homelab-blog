## 概述

通过群晖 DSM 7.2 的反向代理功能，可以用一个端口（或配合运营商放行的 80/443 实现零端口）访问群晖上的多个服务。本文记录 DSM 端反向代理规则的配置，以及运营商处二级域名（CNAME）解析的设置。零端口访问的前提是运营商已开放 80/443 端口，配置步骤本身不变。

## 一、群晖端反向代理设置

1. 打开反向代理配置：`控制面板` → `登录门户` → `高级` → `反向代理服务器`。

## 二、域名运营商解析二级域名

在域名运营商处添加 CNAME 记录，将二级域名指向你的服务器主域名。以阿里云为例：

| 记录类型 | 主机记录 | 记录值    | TTL  |
| -------- | -------- | --------- | ---- |
| CNAME    | subdomain  | your-domain  | 默认 |

即把 `subdomain.your-domain` 解析到群晖所在的主域名，再由群晖反向代理按子域名分发到对应内网服务。

> [!NOTE]
> 不同运营商控制台措辞略有差异（腾讯云、Cloudflare 等同为 CNAME 记录），字段含义一致：主机记录即二级子域名前缀，记录值填主域名。
