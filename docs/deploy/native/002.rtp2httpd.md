> rtp2httpd - IPTV 流媒体转发服务器
>
> 官网：[https://rtp2httpd.com/](https://rtp2httpd.com/)
>
> Github：[https://github.com/stackia/rtp2httpd](https://github.com/stackia/rtp2httpd)

## 0. 前置
- iptv 是 Debian 13（其他 Debian/Ubuntu 同理）
- ens224 网卡已由 ESXi 添加（vIPTV vSwitch），确认存在：`ip link show ens224`

## 1. 网卡配置（netplan，持久化）
```bash
cat > /etc/netplan/99-custom.yaml <<'EOF'
network:
  version: 2
  ethernets:
    ens192:
      dhcp4: false
      dhcp6: false
      addresses:
        - 10.0.0.8/24
      gateway4: 10.0.0.1
      nameservers:
        addresses:
          - 10.0.0.2
    ens224:
      dhcp4: false
      dhcp6: false
      addresses:
        - 172.16.1.1/24
EOF
chmod 600 /etc/netplan/99-custom.yaml
netplan apply
ip -br addr show ens224    # 应显示 172.16.1.1/24
```
> [!IMPORTANT]
> ens224 **必须有 IPv4 地址**（实测：无 IP 时 join 失败），私有段任意（光猫推流不看源 IP 网段）；**不加网关**

## 2. 获取 rtp2httpd 二进制（三选一）

### 方式 A（推荐）：官方 release 静态二进制

>最简单，无需任何依赖，自动获取最新版

```bash
VER=$(curl -s https://api.github.com/repos/stackia/rtp2httpd/releases/latest | grep -oP '"tag_name": *"\K[^"]+')
curl -L -o /usr/local/bin/rtp2httpd \
  "https://github.com/stackia/rtp2httpd/releases/download/${VER}/rtp2httpd-${VER#v}-x86_64"
chmod +x /usr/local/bin/rtp2httpd
```
> [!NOTE]
> 官方 release 的 `rtp2httpd-<版本>-x86_64` 是**完全静态编译**（`ldd` 显示 not a dynamic executable）——任何 Linux 直接跑，**不需要 musl/编译**，版本自动跟随最新（asset 命名规则 = tag 去掉 `v` 前缀 + `-x86_64`）。无 .deb 包，x86_64 静态二进制即 Debian 可用形态

### 方式 B：从官方镜像提取

> 需要有 docker 的机器，如 Ubuntu

```bash
docker pull ghcr.io/stackia/rtp2httpd:latest
docker create --name r2h-tmp ghcr.io/stackia/rtp2httpd:latest
docker cp r2h-tmp:/usr/local/bin/rtp2httpd ./rtp2httpd
docker rm r2h-tmp
scp rtp2httpd root@10.0.0.8:/usr/local/bin/rtp2httpd
```

### 方式 C：源码编译

> iptv 上直接编，不需要 docker

```bash
apt update && apt install -y git cmake gcc make
git clone https://github.com/stackia/rtp2httpd.git /tmp/rtp2httpd-src
cd /tmp/rtp2httpd-src
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
install -m755 build/rtp2httpd /usr/local/bin/rtp2httpd
```

## 3. 运行依赖 + 启动服务
```bash
apt install -y musl          # musl 动态链接库（方式 A 的二进制需要；方式 B 编译的可跳过但装了无害）
chmod +x /usr/local/bin/rtp2httpd

cat > /etc/systemd/system/rtp2httpd.service <<'EOF'
[Unit]
Description=rtp2httpd IPTV
After=network.target

[Service]
ExecStart=/usr/local/bin/rtp2httpd --noconfig --verbose 2 --listen 0.0.0.0:5140 --maxclients 20 --upstream-interface-multicast ens224
Restart=always

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload
systemctl enable --now rtp2httpd
```
> [!IMPORTANT]
> 关键参数：**`--upstream-interface-multicast ens224`**（从光猫网卡发 IGMP join）——漏了它就收不到流（503）

## 4. 验证
```bash
curl http://127.0.0.1:5140/status                      # 返回状态页 = 服务正常
curl -o /dev/null -w "%{http_code} %{size_download}\n" \
  http://127.0.0.1:5140/rtp/239.49.8.19:9614           # 200 + 每秒约 1MB+ = 有流
# 全屋播放：http://10.0.0.8:5140/rtp/239.49.8.19:9614
```
